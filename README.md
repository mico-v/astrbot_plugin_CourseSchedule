# astrbot_plugin_course_schedule

AstrBot 课程表插件，用于保存、查询和展示群友课程表。课程表以标准 iCalendar（`.ics`）作为导入/导出格式，本地使用 SQLite 持久化；支持文件消息自动导入及群文件引用后 @机器人触发导入。

## 功能

- 使用标准 `icalendar` 包解析和生成 `.ics`。
- 按会话作用域和 QQ 号保存每个人的课程表。
- 支持 RRULE、RDATE、EXDATE 等重复课程信息。
- 生成当前会话今日课程表图片。
- 生成指定日期的课程表图片，日期支持 `2026-09-17`、`9.17`、`9月17日`、`昨天`、`明天` 等写法。
- 生成群友上课时长排行榜图片，支持今日、本周、上周、本月、上月和自定义日期范围。
- 支持 `/休假`、`/调休` 标记假期和调休上课，可作用于全体成员或指定成员。
- 在 AstrBot WebUI 的插件 Pages 中按群组、成员手动增删改课程，并同步保存到本地 ICS。
- 在 WebUI 中按群成员批量创建新课表：读取群成员并自动过滤已有课表的成员。
- 向 AI 暴露聚合的 `find` 查询工具和 `edit` 编辑工具，避免 Agent 在多个重复工具之间选择。
- 图片渲染统一使用内置 Noto Sans CJK SC 字体绘制中文、英文、数字和普通符号；仅当该字体确实缺少 Emoji 字形时，才回退到内置 Noto Color Emoji（彩色，含系统 Emoji 字体）逐个字符簇兜底。

今日课表图片按成员分卡片展示：正在上课、下一节即将上课、今日课程已结束和今日无课分别使用不同状态色；当天的当前课程会显示本节时长、距下课/上课倒计时和进度条。昵称中的 Unicode Emoji（包括国旗、肤色和 ZWJ 组合表情）会使用 Emoji 字体单独绘制，优先使用彩色 Emoji 字体，避免 CJK 字体缺字。

当天的课程已经上完、当天没有课或被标记为休假的成员，会收纳到卡片下方的「没有课的群友」条带里，用小头像和昵称按网格排列（一行可显示多位），只在标题里报一次人数。所以一个大部分人都已下课的群，图片不会因为几十张「已结束」卡片而变得很长。

收纳的判断依据是「那天还有没有剩余课程」，与查看的是哪一天无关：查明天、后天或任意日期时，那天没课的成员同样收进条带，卡片始终表示还有课要上的人。条带标题会跟着日期变化（当天是「今天已经没有课的群友」，其它日期是「09-20 没有课的群友」）。注意查过去的日期时那天已经结束，所有人的课程都算上完，因此会全部收进条带。

上课时长榜按成员在统计区间内的课程占用时长排名，名次前列使用不同的强调色，卡片上同时给出节数、门数、已上时长和相对榜首的时长占比。

在 AstrBot WebUI 打开本插件详情页中的“课表管理” Page，即可选择已保存课表的群组和成员，编辑显示名称、课程名称、起止时间、地点、备注和重复规则。保存时会校验课程时间并使用 revision 防止覆盖其他操作；若页面提示课表已更新，请刷新后再保存。

每个群组右侧的 `＋` 按钮可以批量创建新课表：点击后会读取该群的全部成员并过滤掉已经有课表的
成员，勾选后点击“添加课表”即可创建空白课表，随后在右侧编辑课程。群成员列表通过消息平台的
`get_group_member_list` 接口获取（OneBot / aiocqhttp 适配器），需要机器人已加入该群并且在线；
读取失败时页面会给出提示。该功能只针对已经保存过课表的群组，群组本身会随成员课表的导入自动出现。

课程表数据保存于 AstrBot 的插件数据目录：

```text
data/plugin_data/astrbot_plugin_course_schedule/
├── course_schedule.sqlite3   # 课表数据库
├── avatars/                  # QQ 头像缓存（TTL 1 天）
└── images/                   # 生成的课表图片（超过 1 天自动清理）
```

插件使用 SQLite 按“作用域 + QQ 号”保存成员记录，`VEVENT` 事件独立保存于 `course_events` 表，
休假/调休标记保存于 `schedule_day_overrides` 表；写入使用事务和 revision 乐观锁。
头像只用于卡片展示，按 QQ 号缓存 1 天后重新抓取，超时或抓取失败时用昵称首字兜底并短暂缓存。

## ICS 导入

发送 `/导入课表` 并附加 `.ics` 文件即可导入。插件按 AstrBot 标准
`event.get_messages()` 消息链读取 `File` 消息段，并调用 `await File.get_file()` 获取本地文件；
独立的 `.ics` 文件消息也会交给自动导入处理器。
导入成功后会在当前会话作用域内按发送者 QQ 号写入 SQLite，并保留原始 ICS 内容。

按群文件约定命名的 `schedule<QQ号>.ics` 会写入该 QQ 号对应的成员课表，因此
**为其他成员导入需要管理员权限**，和 `edit`、`/休假` 的规则一致；普通成员只能导入自己的课表，
私聊也只能导入自己的。文件不带该命名时，导入对象是发送者本人。
插件不会调用 OneBot 群文件上传、下载或删除 API。

## 聊天命令

```text
/今日课表
/明日课表
/课表 [日期]
/上课时长榜 [统计范围]
/休假 <日期> [成员]
/调休 <日期> <来源日期> [成员]
/销假 <日期> [成员]
/假期
/导入课表 + .ics 附件
```

`/今日课表` 生成当前会话今日课程表图片。
`/明日课表` 复用同样的成员卡片图片样式，生成当前会话明日课程表图片。
`/课表` 生成指定日期的课程表图片，不带日期时等同于今日：

```text
/课表                → 今天
/课表 9.17
/课表 9月17日
/课表 2026-09-17
/课表 明天
/课表 昨天
```

日期写成 `2026-09-17`、`2026/9/17`、`2026年9月17日`、`9.17`、`9月17日`，或 `前天`、`昨天`、
`今天`、`明天`、`后天`、`大后天` 都可以；`明天的课` 这样带虚词的写法也能识别。
不带年份的日期取离今天最近的一次，所以 `9.1` 是本月 1 日而不是明年，过去和将来的某一天都能查。
一次只能查看一天，写成日期范围（`9.17..9.19`）或列出多个日期时会提示改用单个日期。
图片标题带星期，副标题标出「昨天 / 明天 / N 天后」，查询过去的日期时页脚显示为「历史课表」。

`/上课时长榜` 生成当前会话的群友上课时长排行榜图片，别名 `/上课排行`、`/本周上课排行`、`/学习时长榜`。

```text
/上课时长榜              → 本周
/上课时长榜 今日
/上课时长榜 上周
/上课时长榜 2026-09-01..2026-09-30
```

统计范围为 今日、明日、昨天、本周、上周、本月、上月、下周、下月，或 `YYYY-MM-DD..YYYY-MM-DD` 日期范围，最长 366 天。
日期范围写在空格两侧也可以（`2026-09-01 .. 2026-09-30`）。
时长按课程**占用时间**计算：同一时段的两门课只计一次，跨天课程只计入落在统计区间内的部分，全天日程（只有日期没有时刻的事件）不计入，重复课程按 RRULE 展开逐次计入。统计区间内的课程全部计入，未开始的部分单独显示为"已上 X / 共 Y"，所以同一周内榜单数字不会因为时间推移而变化。
图片默认展示时长最长的前 20 位成员。

## 休假与调休

```text
/休假 <日期> [成员]
/调休 <日期> <来源日期> [成员]
/销假 <日期> [成员]
/假期
```

`/休假` 把某天的课程全部取消；`/调休` 让某一天的课程改为另一天的课程。日期支持
`2026-10-01`、`10月1日`、`今天`、`明天`，也支持 `10月1日至10月8日` 这样的范围，
范围两侧带空格（`10月1日 .. 10月8日`）同样可以。

```text
/休假 2026-10-01              → 管理员：全体成员；普通成员：自己
/休假 2026-10-01 @小明
/休假 10月1日至10月8日
/调休 2026-10-11 2026-10-08   → 10 月 11 日按 10 月 8 日的课程上课
```

调休会被覆盖的日期原有课程全部取消，来源日期本身不受影响；即使来源日期自己也被标记为
休假，调休当天仍按来源日期的课程上课。国庆这类"10 月 8 日放假、10 月 11 日补 10 月 8 日
的课"的通知，依次执行 `/休假 2026-10-08` 和 `/调休 2026-10-11 2026-10-08` 即可。

权限与 `edit` 工具一致：管理员不指定成员时默认标记全体成员（`/销假` 同理），也可以用 QQ 号、
完整昵称或 @ 目标单独指定；群聊中普通成员只能标记自己，私聊也只能标记自己。`/销假` 取消
标记，普通成员不能取消管理员设置的全体成员标记。`/假期` 列出当前会话的全部标记。

标记会作用到今日/明日/课表图片、`find` 查询、上课时长榜和 SQL 查询：重复课程按 RRULE
展开后仍然会被取消或替换，成员自己的标记优先于全体成员标记。标记保存在 SQLite 的
独立表中，重新导入 `.ics` 不会清除标记。图片中休假成员的卡片显示"休假 · 无课程安排"，
调休当天显示"调休 · 按 MM-DD 的课表"。

## AI 工具调用

插件只向 Agent 暴露两个聚合工具：

```text
find(person="", time_range="", field="", value="")
edit(action, person="", course_id=0, course="", start_time="", end_time="", location="", description="", rrule="", member_name="", clear_fields="")
```

`find` 不需要拼接 SQL：

- `person` 使用 QQ 号或完整昵称精确查找；留空表示发送消息的用户；查找全部成员时显式传入 `all`、`全部` 或 `所有`。
- `time_range` 留空、`all` 或 `全部` 查找全部已保存的课程事件；也支持今天、明天、本周、
  本月、单个日期、`YYYY-MM-DD..YYYY-MM-DD` 日期范围和完整日期时间范围。指定范围时会展开
  RRULE、RDATE、EXDATE。
- `field/value` 可按课程名、地点、备注、状态、日期、星期、成员、QQ 号、时长或重复规则筛选。
  课程名、地点、备注和重复规则支持包含匹配，成员、状态、日期、星期、QQ 号使用精确匹配。
- 每条结果包含成员、时间、状态、时长和 `course_id`；`course_id` 可以直接交给 `edit`。

`edit` 的 `action` 支持 `create/add`、`update/edit`、`delete/remove`，也支持新增、修改、删除等中文。
新增课程必须填写 `course`、`start_time` 和 `end_time`；新增目标没有课表时会自动创建成员记录。
管理员可以传目标 QQ 号，或在当前消息中 @ 目标用户并传入其昵称来创建尚未登记的成员；仅凭一个
从未登记且未被 @ 的昵称无法确定对应 QQ 号，插件会要求补充 QQ 号或 @ 目标。
修改和删除使用 `find` 返回的 `course_id`，留空的修改字段保持原值；通过 `clear_fields` 可以清空
地点、备注或重复规则。`member_name` 可设置或修改成员昵称。

私聊只能编辑自己的课表。群聊中普通成员只能编辑自己的课表；管理员可通过同一个 `edit` 工具指定
其他成员的 QQ 号或完整昵称进行增删改，管理员身份由 AstrBot 消息事件校验。所有编辑都会执行时间
校验、revision 乐观锁写入、SQLite 更新和 ICS 重建。

工具均返回字符串给模型，不会直接向聊天窗口发送文本结果。

## 开发调试

1. 将本仓库放到 AstrBot 的 `data/plugins/astrbot_plugin_course_schedule` 目录下。
2. 安装插件依赖：`uv pip install -r requirements.txt`，或使用 AstrBot 插件管理器安装。
3. 在 AstrBot WebUI 插件管理中重载插件。
4. 发送 `/今日课表`，或用自然语言请求机器人查询/修改本地课程表。
